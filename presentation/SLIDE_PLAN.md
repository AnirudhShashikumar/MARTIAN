| Slide | Required content | Provisional AccessRelay mapping |
| --- | --- | --- |
| 1 · Team submission | Team name, leader, chosen domain, problem | Management · Track 4, accessible class continuity after a campus access outage |
| 2 · Problem | Campus problem, affected users, impact and limits of current solutions | Lift fails, classroom loses its step-free route. Show the facilities → registrar → instructor handoff and the documented comparator. |

| 6 · Feasibility | 24-hour build scope, components, hardware and scale path | Local web UI, Python API and SQLite, laptop only. Schedule against the **actual** 16.5-hour elapsed finale window and confirmed break/deadline. |
| 7 · Team | Leader details, members and declared tools | Fill from team-confirmed roster and the tools actually used. |

| Narrative beat | What the judge should take away |
| --- | --- |
| Hook and identity | A clear campus stakeholder encounters a consequential bottleneck. |
| Problem and evidence | The bottleneck is real, and its cause is understood. |
| Current workflow and gap | Existing workflows leave a specific need unresolved. |
| Proposed solution | One new core capability changes the user’s outcome. |
| Agentic workflow | The agent makes an important decision, acts within permissions, verifies and adapts or escalates. |
| Architecture | The team can explain the components, data, state and controls. |
| Differentiation | The most relevant alternatives have been compared on meaningful capabilities. |
| Feasibility and roadmap | The critical path, dependencies and fallback fit the build window. |
| Impact and evaluation | The team can measure the outcome against a relevant baseline. |
| Close | The judges know exactly why to advance the team and what it will prove. |

One editor owns deck assembly and export. Research supplies cited claims, architecture supplies the diagrams and build sequence, and the presenter times the story. Use a consistent slide brief, run the panel review, fix major objections, rehearse, reopen the submitted-format file and verify receipt.
