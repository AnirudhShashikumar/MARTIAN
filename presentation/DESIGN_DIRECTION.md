# Design direction

Use the official template when supplied. For an unrestricted deck, use a restrained deep navy, warm orange accent and clean neutrals. Keep typography consistent, contrast high and diagrams legible in projection. Use whitespace for hierarchy and a consistent visual language for user, agent, tool and approval steps.

Prioritize the workflow diagram, architecture diagram and one permitted concept mockup if it clarifies the journey. Use charts only where evidence supports them. Open the export for a quick projection-size review of type, labels, layout and image quality.
