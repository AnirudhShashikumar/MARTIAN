# Validation plan

After selection, define a realistic baseline, representative cases and pass criteria for the core workflow. For each metric, record its unit, baseline procedure, planned target, sample size, data origin, owner and what would count as a failure. Choose metrics tied to the problem, such as task success, resolution time, false positives or human intervention.

Plan at least a normal path, an unavailable dependency, an ambiguous input and an approval or escalation case where relevant. In Round 2, collect versioned observations, distinguish real and simulated inputs, and report limitations and measured results separately from planned targets.
